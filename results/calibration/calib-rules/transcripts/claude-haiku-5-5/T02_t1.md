## Setup

The server zone is America/New_York. On 2024-11-03 the clocks fall back at 02:00 EDT (06:00Z), so the local day runs from 00:00 EDT (04:00Z) to 00:00 EST the next day (05:00Z on 2024-11-04). That is the half-open interval S_day = [2024-11-03T04:00Z, 2024-11-04T05:00Z), which is 25 hours long.

Each resource's value in UTC:

| id | Value (UTC) | Notes |
|---|---|---|
| k-01 | 11-03 04:30 | in day |
| k-02 | 11-03 03:30 | = 11-02 23:30 EDT, before day |
| k-03 | 11-04 04:30 | = 11-03 23:30 EST, in day |
| k-04 | 11-04 05:00 | = 11-04 00:00 EST, just after day |
| k-05 | 11-03 05:30 | 01:30 EDT, in day |
| k-06 | 11-03 06:30 | 01:30 EST, in day |
| k-07 | 11-03 06:30 | 12:00+05:30, in day |
| k-08 | whole local day | date-only, equals S_day |
| k-09 | 11-04 04:45 | 23:45 EST, in day |
| k-10 | month 2024-11 | spans far beyond the day |
| k-11 | [11-03 02:00, 11-03 11:00) | period overlapping the day, not contained |
| k-12 | 11-03 05:00 | 01:00 EDT, in day |
| k-13 | 11-03 06:00 | 01:00 EST, in day |

## Query results

**q1, `date=2024-11-03` (eq):** every instant of T must lie inside S_day. The in-day instants match (k-01, k-03, k-05–k-09, k-12, k-13). k-02 and k-04 fall outside. k-10 is a month that is not contained in the day. k-11 starts at 02:00Z, before the day begins, so it is not contained.

**q2, `date=ge…01:00-04:00 & date=lt…01:00-05:00`:** the first clause is ge with S1 = [05:00Z, 05:01Z), so T.end > 05:00Z. The second is lt with S2 = [06:00Z, 06:01Z), so T.start < 06:00Z. Both must hold. Matches: k-05 (05:30Z), k-08 (overlaps the whole day), k-10 (month overlaps), k-11 (period overlaps), k-12 (05:00Z). Excluded: k-13 (start is exactly 06:00Z, not before it), k-06 and k-07 (06:30Z), and k-01 and k-09 (too early or too late).

**q3, `date=sa2024-11-03`:** T.start must be at or after the end of S_day (05:00Z on 11-04). Only k-04 qualifies (05:00:00Z exactly, which is at or after the end). k-03 at 04:30Z on 11-04 does not.

**q4, `date=eb2024-11-03`:** T.end must be at or before the start of S_day (04:00Z on 11-03). Only k-02 (03:30Z) qualifies. k-10 and k-11 start before the day and extend past it, so they do not.

**q5, `date=ne2024-11-03`:** every resource has an indexed value, so ne is the complement of q1. The complement is k-02, k-04, k-10, k-11.
