General
  * Parameters joined by & must all match (AND). Repeating a parameter name is also AND,

Dates and times
  * Every date, dateTime or instant (in a resource or in a query) denotes a half-open
    interval [start, end) set by its precision: YYYY = the whole year, YYYY-MM = the whole
    month, YYYY-MM-DD = the whole day, YYYY-MM-DDThh:mm = that minute,

    (including every date-only, year-month and year value) is in the server's local time

## Reply

**Approach:** Quantity searches use the implicit range for `eq`/`ne` (number "100" = [99.5, 100.5), "100.0" = [99.95, 100.05)). `gt`, `lt`, `ge`, and `le` compare the exact number. System and code must match when given. With `||kg`, either `Quantity.code` or `Quantity.unit` must equal `kg`. w-10 has no `valueQuantity`, so it never matches any query.

**q1** `100|ucum|kg`, range [99.5, 100.5), system and code must match:
- Matches: w-01 (100), w-02 (100.4), w-04 (99.5, lower bound inclusive), w-06 (100.04), w-07 (99.94), w-09 (100.0, code kg).
- Excluded: w-03 (100.5 is outside the half-open range), w-05 (lb), w-08 (no system or code), w-10 (no quantity).

**q2** `100.0|ucum|kg`, range [99.95, 100.05):
- Matches: w-01 (100), w-06 (100.04), w-09 (100.0).
- Excluded: w-07 (99.94 is below 99.95), w-02 and w-03 (too high), w-04 (99.5), w-08 (no system or code).

**q3** `100||kg`, range [99.5, 100.5), any system, code OR unit = kg:
- Matches: w-01, w-02, w-04, w-06, w-07, w-09, and w-08 (matched via `unit`="kg", since it has no `code`).
- Excluded: w-03 (100.5), w-05 (220.5 lb), w-10 (no quantity).

**q4** `gt100|ucum|kg`, exact value > 100:
- Matches: w-02 (100.4), w-03 (100.5), w-06 (100.04).
- Excluded: w-01 and w-09 (exactly 100), w-04 and w-07 (below 100), w-08 (no system or code).

**q5** `ne100|ucum|kg`, value outside [99.5, 100.5), system and code must match:
- Matches: w-03 (100.5 is outside the half-open range).
- Excluded: w-01, w-02, w-04, w-06, w-07, w-09 (inside the range), w-05 (code `[lb_av]`, not `kg`), w-08 (no system or code), w-10 (no value, and `ne` never matches a resource with no value).

**q6** `lt100.0||kg`, exact value < 100.0, code OR unit = kg:
- Matches: w-04 (99.5), w-07 (99.94).
- Excluded: w-01, w-08, w-09 (exactly 100), w-02, w-03, w-06 (above 100), w-05 (lb, and 220.5 is not below 100), w-10 (no quantity).
