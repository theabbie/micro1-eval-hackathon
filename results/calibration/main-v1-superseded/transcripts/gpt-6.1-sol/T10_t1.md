## Reply

Default string searches ignore case and accents and match prefixes, including the server’s defined family-name parts. `:contains` matches anywhere within a whole element value; `:exact` requires the whole value with matching case and accents. Old names remain searchable.

Identifier values match exactly, preserving leading zeros. Without a system, any identifier system can match; `:of-type` additionally requires the specified identifier type.
