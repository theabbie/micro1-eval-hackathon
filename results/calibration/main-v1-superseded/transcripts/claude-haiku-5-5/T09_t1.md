## Reply

**Key points**

- **q1 vs q2:** q1 uses two separate parameters, so the diastolic-code component and the `>=90` value can come from different components. Only the composite q2 requires both on the same component.
- **Status:** The server doesn't filter `entered-in-error` by default, so bp-08 matches wherever its values qualify. Only q3 excludes it, via `status=final`.
- **Missing values:** bp-06's diastolic component has only a `dataAbsentReason`, so it can never match a diastolic value criterion. It still matches q1 and q3 through its systolic 160.
- **Implicit range:** `140` (eq) is treated as [139.5, 140.5), so bp-09's 139.6 matches q5.
- **Top-level vs component:** Panels have no top-level `valueQuantity`, and their `code` is 85354-9. So q6 and q7 only see the standalone systolic and heart-rate Observations.

**Per query**

- **q1** (`component-code=8462-4` AND `component-value-quantity=ge90`, not composite): Every panel has a diastolic-code component. Every panel also has a component ≥ 90, since all systolic values are ≥ 120. The match is therefore all nine panels, including bp-06 (systolic 160) and bp-08 (entered-in-error, not filtered). hr-01 and sbp-01 have no components.
- **q2** (composite diastolic ≥ 90 on the same component): Diastolic ≥ 90 for bp-02 (95), bp-04 (92), bp-07 (90, inclusive), and bp-08 (91, not filtered). bp-06 has no diastolic value. bp-09 is 89.6, which is below 90.
- **q3** (systolic ≥ 140 OR diastolic ≥ 90, AND status=final): Systolic ≥ 140 gives bp-01, bp-04, bp-06, bp-07. Diastolic ≥ 90 gives bp-02, bp-04, bp-07, bp-08. The union is bp-01, bp-02, bp-04, bp-06, bp-07, bp-08. Removing bp-08 for `status=final` leaves five results.
- **q4** (two AND-ed composite parameters, resource-level): Systolic ≥ 140 gives bp-01, bp-04, bp-06, bp-07. Diastolic ≥ 90 gives bp-02, bp-04, bp-07, bp-08. The intersection is bp-04 and bp-07.
- **q5** (systolic eq 140, implicit range [139.5, 140.5)): bp-07 (140) and bp-09 (139.6) match. bp-01 (150), bp-04 (145), and bp-05 (135) do not.
- **q6** (`code-value-quantity`, code 8480-6 AND value ge 140): Only the top-level standalone systolic Observation qualifies. sbp-01 (152) matches. Panels have code 85354-9 and no top-level value.
- **q7** (`value-quantity=gt90`, top-level only): hr-01 (98) and sbp-01 (152) match. Panels have no top-level `valueQuantity`.
