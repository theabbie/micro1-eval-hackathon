## Reply

**Key rules applied**

- **Time zone:** Offsetless values (`2024`, `2024-07-02`) and queries are read in America/New_York. Offset values are converted to local time before date matching. This moves a1c-02 (`2025-01-01T03:00Z` = 2024-12-31 22:00 EST) into 2024, and a1c-03 (`2024-01-01T02:00Z` = 2023-12-31 21:00 EST) out of 2024.
- **Date ranges:** `date=2024-12-31` (eq) matches anything whose range overlaps that local day. The year value `2024` covers all of 2024, so it overlaps.
- **Systems:** `http://loinc.org|4548-4` requires the LOINC system. `4548-4` with no system matches any system. `|4548-4` matches only codings with no system.
- **Quantity:** `8.0` has one decimal place, so eq uses the implicit range [7.95, 8.05). The upper bound is exclusive, so 8.05 is excluded and 7.95 is included. `gt9` is an exact comparison.
- **Status and code filters:** Q3 and Q4 have no status filter, so entered-in-error and corrected resources still match if the other criteria are met.

**Per query**

- **q1:** Code is LOINC 4548-4 or 17856-6, status is final/amended/corrected, and local date is 2024-01-01 to 2024-12-31.
  - Matches: a1c-01 (2024-03-14), a1c-02 (local 2024-12-31), a1c-04 (amended, 17856-6), a1c-08 (corrected, 2024-11-20), a1c-09 (year 2024).
  - Excluded: a1c-03 (local 2023-12-31), a1c-05 (entered-in-error), a1c-06 (preliminary), a1c-07 (local-lab system), a1c-10 (different code), a1c-11 (no system), a1c-12 (local 2025-01-01).
- **q2:** LOINC 4548-4, status final/amended/corrected, value > 9 with UCUM `%`.
  - Matches: a1c-02 (9.4), a1c-12 (9.1).
  - Excluded: a1c-03 (9.0 is not > 9), a1c-06 (9.6 but preliminary).
- **q3:** Code 4548-4 in any system, value in [7.95, 8.05), no unit or status constraint.
  - Matches: a1c-05 (8.01, entered-in-error), a1c-08 (7.95, corrected), a1c-11 (8.0, no system).
  - Excluded: a1c-07 (8.05 is outside the exclusive upper bound), a1c-04 (wrong code, 8.04).
