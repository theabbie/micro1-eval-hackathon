## Reply

**Assumptions**

- Local zone is America/Chicago: CDT (UTC−5) from March to early November, CST (UTC−6) otherwise.
- Only `occurrenceDateTime` is indexed for `date`. `occurrenceString` is not date-typed, so imm-03 and imm-10 have no indexed date value.
- Date prefixes follow the R4 prefix table. For `eq`, the search range must fully contain the target range. For `ne`, it must not fully contain the target range.
- Resource times are converted to local time:

| id | Stored value | Local (America/Chicago) |
|---|---|---|
| imm-01 | 2019-05-14 | 2019-05-14 (day) |
| imm-02 | 2019 | 2019-01-01 to 2019-12-31 |
| imm-04 | 2019-05 | 2019-05-01 to 2019-05-31 |
| imm-05 | 2019-06-01T03:30Z | 2019-05-31T22:30 |
| imm-06 | 2018-12-31T23:00-06:00 | 2018-12-31T23:00 |

| imm-08 | 2020-01-01T05:30Z | 2019-12-31T23:30 |
| imm-09 | 2019-05-31T23:59:00 | 2019-05-31T23:59 |

**Per-query reasoning**

- **q1 `date=2019-05`** (eq, range fully contained in May 2019): imm-01, imm-04, imm-05, imm-07, imm-09 match. imm-02 is excluded because the year 2019 is not contained in May.
- **q2 `date=ne2019-05`** (not fully contained in May 2019): imm-02 (year 2019 extends beyond May), imm-06 (Dec 2018), imm-08 (Dec 2019). Resources with no indexed date do not match `ne`.
- **q3 `date=2019`** (eq, range fully contained in 2019): every indexed resource dated in 2019 matches, including imm-02 (same range) and imm-08 (2019-12-31 local). imm-06 (2018) is excluded.
- **q4 `date=le2019-05-31&status=completed`**: the range below ends at the search start (2019-05-31 00:00), and `le` also matches any overlap with the search range. Matches are imm-01, imm-02 (overlaps), imm-04, imm-05 (22:30 local on 05-31), imm-06 (earlier), and imm-09 (23:59 on 05-31). imm-07 is excluded by `status`. imm-08 is excluded because it is in December 2019.
- **q5 `date:missing=true`**: only resources with no indexed date value match. Those are imm-03 and imm-10, which have only `occurrenceString`.
- **q6 `vaccine-code=…|03&date=gt2019-05-14`**: the code-03 resources are imm-01, imm-02, and imm-03. The range above starts at the end of 2019-05-14, so imm-01 (which ends there) does not overlap it. imm-02 (2019) extends past that point and matches. imm-03 has no indexed date and is excluded.
