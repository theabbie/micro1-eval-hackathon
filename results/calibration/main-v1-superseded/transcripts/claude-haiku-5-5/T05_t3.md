## Reply

**Assumptions:** Undated-offset values are interpreted in America/Los_Angeles (PST, UTC−8, in January; PDT, UTC−7, after DST starts). Date prefixes follow the R4 date rules as the server describes them. `lt`/`gt` match on range intersection, `eq` requires the target range to be fully contained in the search range, and `ge`/`le` add overlap with the search day. Only `onsetDateTime` and `onsetPeriod` are indexed for `onset-date`. `onsetAge` and `onsetString` are not indexed. Token codes are case-sensitive, and a token with no system matches on code alone.

**Indexed onset values (local time):**
- c-01: 2018-03-02
- c-02: 2019-07-01
- c-03: Age (not indexed)
- c-04: string (not indexed)
- c-05: Period 2019-10-01 00:00 to 2020-02-29 23:59:59
- c-06: 2015 (year range)
- c-07: 2020-01-01T07:30Z = **2019-12-31 23:30 PST**
- c-08: 2020-01-01T09:00Z = **2020-01-01 01:00 PST**
- c-09: 2017-05-05 (entered-in-error)
- c-10: 2016-08-19
- c-11: no onset

**q1** `clinical-status=active` AND `onset-date<2020-01-01`
- Active resources: c-01, c-03, c-04, c-05, c-07, c-08. (c-10 is excluded because its code is `Active`, and the system doesn't match.)
- c-01 (2018) matches. c-05 starts in 2019, so its range intersects the range below 2020-01-01. c-07 is 2019-12-31 23:30 local, so it matches.
- c-03 and c-04 have no indexed onset. c-08 is on 2020-01-01 local, so it does not match.

**q2** `clinical-status=active|recurrence|relapse` AND `onset-date>=2020-01-01`
- c-05: its range runs into Feb 2020, so it overlaps the range above. Match.
- c-08: 2020-01-01 01:00 local lies inside the search day, so it overlaps the search range. Match.
- c-07 is 2019-12-31 local, so it does not match. c-01 and c-02 are too early. c-03 and c-04 have no indexed onset.

**q3** `onset-date:missing=true`
- Resources with no indexed onset date: c-03 (Age), c-04 (string), c-11 (none).
- All others have an indexed date.

**q4** `clinical-status:not=active`
- Resources that do not match `active`, including those with no value: c-02, c-06, c-09 (no clinicalStatus), c-10 (`Active` does not match case-sensitively), c-11.

**q5** `onset-date=2019`
- Search range is the whole of 2019 local. Targets must be fully contained within it.
- c-02 (2019-07-01) matches. c-07 (2019-12-31 23:30 local) matches.
- c-05 extends into 2020, so it is not fully contained and does not match. c-08 is in 2020.
