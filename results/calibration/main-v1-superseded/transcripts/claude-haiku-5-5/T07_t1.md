**Assumptions**
- Quantity matching uses `Quantity.system` and `Quantity.code`, not `unit` text. So w-09 (`unit: "kilograms"`, `code: "kg"`) matches `kg`, and w-08 (no system or code) never matches a query that specifies `kg`.

- w-10 has no `valueQuantity`, so it never matches.
- Implicit ranges are half-open: `100` means [99.5, 100.5), and `100.0` means [99.95, 100.05).
