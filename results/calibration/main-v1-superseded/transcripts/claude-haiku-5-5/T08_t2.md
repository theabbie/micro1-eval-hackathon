## Approach

Each resource's date is converted to a local range in America/New_York. Offsets are converted to UTC, then to local time (EST = UTC-5 before 2024-03-10 02:00, EDT = UTC-4 after). Offset-free values are read as local time. Precision sets the range, so a minute-precision value covers `hh:mm:00` through `hh:mm:59.999`.

| id | Stored value | Local (America/New_York) range |
|---|---|---|
| g-01 | 03-01T00:30+14:00 | 02-29 05:30 EST (minute) |
| g-02 | 02-29T23:30-12:00 | 03-01 06:30 EST (minute) |
| g-03 | 03-31T23:30-04:00 | 03-31 23:30 EDT (minute) |
| g-04 | 04-01T04:30Z | 04-01 00:30 EDT (minute) |
| g-05 | 03-01T04:30Z | 02-29 23:30 EST (minute) |
| g-06 | 03-10T01:59 | 03-10 01:59 EST (minute) |
| g-07 | 03-10T03:00 | 03-10 03:00 EDT (minute; the 02:00–02:59 gap is not used) |
| g-08 | 03-10 | 03-10 00:00 to 23:59:59.999 (day) |
| g-09 | period 02-26 to 03-04 | 02-26 00:00 to 03-04 23:59:59.999 |
| g-10 | 2024-02 | 02-01 00:00 to 02-29 23:59:59.999 |
| g-11 | 03-01T05:00+00:00 | 03-01 00:00 EST (minute) |
| g-12 | 03-01T04:59:59Z | 02-29 23:59:59 EST (second) |
| g-13 | 03-01T10:15+05:45 | 02-29 23:30 EST (minute) |
| g-14 | 03-31T21:00-03:30 | 03-31 20:30 EDT (minute) |
| g-15 | 2024 | 01-01 00:00 to 12-31 23:59:59.999 |
| g-16 | period start 03-15T10:00-04:00, no end | 03-15 10:00 EDT onward (open-ended) |

Rules applied:
- **eq / ne:** the search range fully contains the target range (or it doesn't, for ne).
- **gt:** target high is after the search end (end of the search range is 23:59:59.999 for the day or minute value).
- **ge:** target high is at or after the search start.
- **le:** target low is at or before the search end.
- **eb:** target high is before the search start.
- **sa:** target low is after the search end.
- Repeated `date` parameters are ANDed.

## Per-query results

- **q1** (`2024-02`, eq): targets fully inside February 2024. g-09 spans into March, and g-15 covers the whole year, so neither matches.
- **q2** (`2024-03`, eq): targets fully inside March 2024. g-16 is open-ended, so it does not match.
- **q3** (ge 03-01 AND le 03-31): targets whose high is on or after 03-01 00:00 and whose low is on or before 03-31 23:59:59.999. This includes overlapping and partially overlapping targets (g-09, g-15, g-16).
- **q4** (`eb2024-03-01`): targets ending before 03-01 00:00. The boundary is unambiguous because no target ends exactly at that instant.
- **q5** (`sa2024-03-31`): targets starting after 03-31 23:59:59.999. Only g-04 qualifies.
- **q6** (`ne2024-03`): the complement of q2 across all 16 resources. Every resource has a date-typed value, so there are no empty-value cases.
- **q7** (`gt2024-03-31T23:59-04:00`): the query converts to 03-31 23:59 EDT, so the search end is 23:59:59.999 EDT. Targets whose high is after that match. g-15 matches because the year range extends to 12-31.
