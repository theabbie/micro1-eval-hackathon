## Reply

**Assumptions**
- Quantity search matches `value`, `system` and `code`. Empty system (`||`) means any system. A resource with no `system` or `code` cannot match a query that specifies them.
- `eq` and `ne` use the implicit range of the search number, read per the R4 spec as "the search range fully contains the target's range." The target's own precision also sets its range (e.g. `99.5` → [99.45, 99.55)).
- `gt`/`lt` compare exactly.
- `ne` is the complement of `eq` among resources that have a matching-system/code quantity. Resources with no value (w-10) are not returned, since only `:not` includes them.

**Ranges used**
- `100` (precision 0): [99.5, 100.5)
- `100.0` (precision 1): [99.95, 100.05)

**Per-resource analysis**
- **w-01** (100 kg, UCUM): range [99.5, 100.5) is equal to the search range, so it matches `eq`.
- **w-02** (100.4): range [100.35, 100.45) is contained.
- **w-03** (100.5): range [100.45, 100.55) extends past 100.5, so it fails `eq`.
- **w-04** (99.5): range [99.45, 99.55) extends below 99.5, so it fails `eq`.
- **w-05** (220.5 lb): code is `[lb_av]`, not `kg`, so it never matches.
- **w-06** (100.04): range [100.035, 100.045) is contained in both [99.5, 100.5) and [99.95, 100.05).
- **w-07** (99.94): range [99.935, 99.945) is contained in [99.5, 100.5) but not in [99.95, 100.05).
- **w-08** (100 kg): no `system` or `code`, so it fails any query with `kg` as code or `ucum` as system. It also fails `||kg`, because there is no code.
- **w-09** (100.0, code `kg`): range [99.95, 100.05) matches `100.0` exactly.
- **w-10** (string value): no quantity, so it is never returned.

**Results**
- **q1** (`100|ucum|kg`, range [99.5, 100.5)): w-01, w-02, w-06, w-07, w-09. Excludes w-03 and w-04 (boundary failures) and w-08 (no system).
- **q2** (`100.0|ucum|kg`, range [99.95, 100.05)): w-06, w-09. w-01 is too coarse, and w-07 falls just outside.
- **q3** (`100||kg`, any system, code `kg`): same as q1. w-08 has no code.
- **q4** (`gt100|ucum|kg`, exact > 100): w-02 (100.4), w-03 (100.5), w-06 (100.04).
- **q5** (`ne100|ucum|kg`, complement of range [99.5, 100.5)): w-03 and w-04, the two boundary values that fail `eq`.
- **q6** (`lt100.0||kg`, exact < 100.0, code `kg`): w-04 (99.5), w-07 (99.94). w-01 and w-09 equal 100.0 and are excluded.
