## Query results

**q1 `date=2024-11-03` (eq).** Eq requires the target range to lie fully inside the search day. This returns every resource whose local value falls on 11-03: k-01, k-03, k-05, k-06, k-07, k-08, k-09, k-12, k-13. It excludes k-02 and k-04 (adjacent days), k-10 (month range not contained), and k-11 (period starts on 11-02 local).

**q2 `date=ge2024-11-03T01:00-04:00&date=lt2024-11-03T01:00-05:00` (AND).** The bounds are 05:00Z (ge) and 06:00Z (lt). The effective window is instants in [05:00Z, 06:00Z) on 11-03, plus any range that overlaps it.
- k-05 (05:30Z): match.
- k-08 (day range 04:00Z to 11-04 05:00Z overlaps both bounds): match.
- k-10 (November range overlaps both bounds): match.
- k-11 (period 02:00Z to 11:00Z overlaps both bounds): match.
- k-12 (05:00Z, inside the window): match.
- k-13 (06:00Z, excluded by lt): no.
- k-06 and k-07 (06:30Z): no.
- k-09 (11-04 04:45Z): no.
- k-01 (04:30Z): no. k-02, k-03, k-04: no.

**q3 `date=sa2024-11-03` (starts after).** The target must lie entirely after the day's end (11-04 05:00Z). Only k-04 qualifies, at exactly 05:00Z.

**q4 `date=eb2024-11-03` (ends before).** The target must lie entirely before the day's start (11-03 04:00Z). Only k-02 qualifies (03:30Z). k-01 at 04:30Z is inside the day, and k-11 overlaps it.

**q5 `date=ne2024-11-03`.** Per the R4 definition, ne returns resources whose range is not fully contained in the search range. That is every resource not matched by q1: k-02, k-04, k-10, k-11.

**q6 `date=2024-11-03T01:30-05:00` (eq, minute precision).** The search range is 06:30:00Z to 06:30:59.999Z. Matches are k-06 (06:30Z) and k-07 (06:30:00Z). k-05 (05:30Z) and k-13 (its minute range 06:00–06:00:59Z falls outside) do not match.

Note: none of the queries filters by LOINC code, so every Observation on the server is eligible. The "chemistry" framing in the task does not restrict the results.
