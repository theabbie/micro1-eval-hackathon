## Reply

**Indexing:** `onset-date` indexes only `onsetDateTime` and `onsetPeriod`. The `onsetAge` on c-03 and the `onsetString` on c-04 are not indexed, so those two count as missing. c-11 has no onset at all.

**Instants converted to America/Los_Angeles (PST, UTC-8, in January):**
- c-07: 2020-01-01T07:30Z = 2019-12-31 23:30 PST
- c-08: 2020-01-01T09:00Z = 2020-01-01 01:00 PST
- c-05: period 2019-10-01 00:00 through 2020-02-29 23:59:59.999 PST

**Token matching:** `clinical-status=active` has no system, so it matches code `active` in any system, case-sensitively. c-10 has code `Active` from a local system, so it does not match `active`.

**q1: `clinical-status=active` and `onset-date=lt2020-01-01`**
- Active-coded resources: c-01, c-03, c-04, c-05, c-07, c-08.
- `lt` has no overlap rule here, so the target must lie entirely in the range below 2020-01-01 00:00 PST.
- c-01 qualifies. c-07 (2019-12-31 23:30 PST) also qualifies.
- c-05 extends into 2020, so it does not qualify. c-08 is after the cutoff.
- c-03 and c-04 have no indexed onset.
- Result: c-01, c-07.

**q2: `clinical-status=active,recurrence,relapse` and `onset-date=ge2020-01-01`**
- Status matches: c-01, c-02, c-03, c-04, c-05, c-07, c-08.
- `ge` matches targets above the search range, or overlapping it (2020-01-01 PST, the whole day).
- c-08 (2020-01-01 01:00 PST) overlaps the search day, so it matches.
- c-05 overlaps and runs past it, so it matches.
- c-07 is on 2019-12-31 PST, c-01 and c-02 are earlier, and c-03 and c-04 have no indexed onset.
- Result: c-05, c-08.

**q3: `onset-date:missing=true`**
- c-03 (Age), c-04 (string) and c-11 (no onset) have no indexed value.
- Result: c-03, c-04, c-11.

**q4: `clinical-status:not=active`**
- `:not` also returns resources with no value for the parameter.
- c-02 (`recurrence`), c-06 (`resolved`), c-10 (`Active`, case-sensitive mismatch), c-11 (`inactive`) and c-09 (no `clinicalStatus`) all match.
- Result: c-02, c-06, c-09, c-10, c-11.

**q5: `onset-date=2019`**
- `eq` requires the target to fall within 2019-01-01 00:00 to 2019-12-31 23:59:59.999 PST.
- c-02 (2019-07-01) is within the range.
- c-07 (2019-12-31 23:30 PST) is also within it.
- c-05 spills into 2020, so it does not match.
- Result: c-02, c-07.
