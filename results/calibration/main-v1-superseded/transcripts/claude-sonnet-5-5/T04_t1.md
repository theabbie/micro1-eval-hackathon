**q1 `date=2019-05`** (eq: the search range must fully contain the target range)
- Contained: 01, 04, 05, 07, 09.
- imm-02 is wider than the search range, so it does not match.
- imm-06 and imm-08 fall outside it.

**q2 `date=ne2019-05`** (target range not fully contained in the search range)
- Matches: 02, 06, 08.
- imm-03 and imm-10 have no indexed value, so `ne` does not return them. Only `:not` does that on this server.

**q3 `date=2019`** (search range is 2019-01-01T06:00Z to 2020-01-01T06:00Z)
- Matches: 01, 02, 04, 05, 07, 09.
- imm-08 (2020-01-01T05:30Z) is inside the range, so it also matches.
- imm-06 (2019-01-01T05:00Z) is one hour before the start, so it does not match.

**q4 `date=le2019-05-31&status=completed`**
- `le` matches anything that starts before the end of 05-31 or overlaps the search day.
- By date, that gives 01, 02, 04, 05, 06, 07, 09.
- imm-08 is excluded because it is in December.
- imm-07 is dropped by `status=completed`.
- Result: 01, 02, 04, 05, 06, 09.

**q5 `date:missing=true`**
- Matches 03 and 10, because string occurrences are not indexed.

**q6 `vaccine-code=cvx|03&date=gt2019-05-14`**
- CVX 03 matches imm-01, imm-02 and imm-03.
- The range above 2019-05-14 starts at 2019-05-15 00:00 local.
- imm-01 ends exactly there, so it does not overlap the range above and is excluded.
- imm-02 (all of 2019) overlaps it, so it matches.
- imm-03 has no date and is excluded.
