## Reply

`q1` uses separate component indexes, so the component code and qualifying quantity need not belong to the same component. Thus, a qualifying systolic value can make an observation match despite a non-qualifying diastolic value.

`q2` requires the code and quantity to match within the same component.

`q3` applies OR within the composite parameter, then ANDs `status=final`.

`q4` repeats the composite parameter, so both systolic and diastolic criteria must match. `bp-08` matches despite its status because no status filter is present.

`q5` uses equality with implicit numeric precision, so `140` matches values in the implicit range, including `139.6`.

`q6` searches the top-level Observation code and top-level value quantity, matching only the standalone systolic observation.

`q7` searches only top-level `valueQuantity`, matching the heart-rate and standalone systolic observations.
