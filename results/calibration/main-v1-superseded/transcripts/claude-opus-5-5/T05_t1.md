# FHIR R4 Search Results for Task T05 (Condition onset dates)

**Approach:** All dates are evaluated in the server's local zone, America/Los_Angeles. In January this zone is PST (UTC−8), so the local day 2020‑01‑01 runs from 08:00Z on Jan 1 to 08:00Z on Jan 2. Two timestamps need converting:
- **c‑07** (07:30Z) is local time **2019‑12‑31 23:30**.
- **c‑08** (09:00Z) is local time **2020‑01‑01 01:00**.

Two server rules shape the results:
- **Date indexing:** Only date-typed values are indexed. So `onsetAge` (c‑03) and `onsetString` (c‑04) have no indexed value for `onset-date`.
- **Code matching:** Matching is case-sensitive, so c‑10's local code `Active` does not match `active`.

## q1: `clinical-status=active&onset-date=lt2020-01-01`

- **Status filter:** `active` matches c‑01, c‑03, c‑04, c‑05, c‑07 and c‑08. A token with no system matches any system.
- **Date rule:** `lt` matches when the target range overlaps the range below 2020‑01‑01T00:00 local (08:00Z).

| c‑01 | 2018‑03‑02 | Yes |
