# FHIR R4 Condition search results for T05 (America/Los_Angeles)

**Setup:** January 2020 is in PST (UTC−8). So local `2020-01-01` covers 2020-01-01T08:00Z up to 2020-01-02T08:00Z. Local `2019` ends at 2020-01-01T08:00Z.

**Which values `onset-date` indexes:** Only `onsetDateTime` and `onsetPeriod`. Those are c-01, c-02, c-05 to c-10.
- `onsetAge` (c-03) is not indexed.
- `onsetString` (c-04) is not indexed.
- c-11 has no onset at all.

**How `clinical-status` tokens match:** The queries give a code with no system, so the code matches in any system. Matching is case-sensitive. The local code `"Active"` in c-10 therefore does **not** match `active`.

## q1: `clinical-status=active&onset-date=lt2020-01-01`
- Resources with status `active`: c-01, c-03, c-04, c-05, c-07, c-08.
- `lt` matches when the target overlaps the range before 2020-01-01T08:00Z.
  - c-01 (2018-03-02): matches.
  - c-05 (Period 2019-10 to 2020-02): overlaps, so it matches.
  - c-07 (07:30Z, which is 2019-12-31 23:30 local): matches.
  - c-08 (09:00Z, which is 2020-01-01 01:00 local): no match.
  - c-03 and c-04: not indexed, so no match.
- **Result:** c-01, c-05, c-07

## q2: `clinical-status=active,recurrence,relapse&onset-date=ge2020-01-01`
- The status list (OR) matches c-01, c-02, c-03, c-04, c-05, c-07, c-08.
- `ge` matches when the target overlaps [2020-01-01T08:00Z, ∞).
  - c-05: its period ends at the end of Feb 2020, so it matches.
  - c-08: matches.
  - c-07: falls before 08:00Z, so no match.
  - c-01 and c-02: no match.
- **Result:** c-05, c-08

## q3: `onset-date:missing=true`
- These resources have no indexed date value: c-03 (Age), c-04 (string), c-11 (no onset).
- **Result:** c-03, c-04, c-11

## q4: `clinical-status:not=active`
- Resources that do not match `active`:

  - c-06 (resolved)
  - c-11 (inactive)
  - c-10 (`Active` fails because matching is case-sensitive)
  - c-09 (no clinicalStatus; this server's `:not` returns resources with no value)
- **Result:** c-02, c-06, c-09, c-10, c-11

## q5: `onset-date=2019`
- `eq` matches when local year 2019 fully contains the target.
  - c-02: matches.
  - c-07 (2019-12-31 23:30 local): matches.
  - c-05: the period extends into 2020, so it does not match.
- **Result:** c-02, c-07
