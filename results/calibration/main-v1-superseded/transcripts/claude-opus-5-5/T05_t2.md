Results for T05 below. Server local time is America/Los_Angeles. On 2020-01-01 it is PST (UTC−8), so local 2020-01-01T00:00 is **2020-01-01T08:00Z**.

**Indexing for `onset-date`:** Only `onsetDateTime` and `onsetPeriod` are indexed. `onsetAge` (c-03) and `onsetString` (c-04) are not date-typed, so those resources have no value for this parameter. c-11 has no onset at all.

**Token matching:** `clinical-status=active` without a system matches the code `active` in any system. Matching is case-sensitive, so c-10 (`Active`, local system) does **not** match.

**q1:** `clinical-status=active&onset-date=lt2020-01-01`
- Active: c-01, c-03, c-04, c-05, c-07, c-08.
- `lt` means the "range below" ends at the start of the search range (2020-01-01T08:00Z), so the target must begin before that instant.
  - c-01 (2018-03-02): matches.
  - c-05 (Period start 2019-10): matches.
  - c-07 (07:30Z, which is 2019-12-31 23:30 local): matches.
  - c-08 (09:00Z): does not match.
  - c-03 and c-04: no indexed value.
- Result: c-01, c-05, c-07.

**q2:** `clinical-status=active,recurrence,relapse&onset-date=ge2020-01-01`
- Status matches: c-01, c-02, c-03, c-04, c-05, c-07, c-08.
- `ge` matches a target that overlaps either the search range [2020-01-01T08:00Z, 2020-01-02T08:00Z) or the range above it.
  - c-05 (Period ends 2020-02): overlaps, matches.
  - c-08 (09:00Z): inside the search day, matches.
  - c-07 (07:30Z): before the start, does not match.
  - c-01 and c-02: earlier dates, do not match.
- Result: c-05, c-08.

**q3:** `onset-date:missing=true`
- No indexed onset date: c-03 (Age), c-04 (string), c-11 (none).
- Result: c-03, c-04, c-11.

**q4:** `clinical-status:not=active`
- This returns everything without the code `active`, including resources with no clinical status.
  - c-02: recurrence.
  - c-06: resolved.
  - c-09: no clinicalStatus.
  - c-10: `Active` (case-sensitive mismatch).
  - c-11: inactive.
- Result: c-02, c-06, c-09, c-10, c-11.

**q5:** `onset-date=2019`
- `eq` requires the target to be fully inside [2019-01-01T08:00Z, 2020-01-01T08:00Z).
  - c-02 (2019-07-01): matches.
  - c-07 (2020-01-01T07:30Z, which is 2019-12-31 local): matches.
  - c-05: the Period runs into 2020, so it is not contained.
  - All others: outside 2019.
- Result: c-02, c-07.
