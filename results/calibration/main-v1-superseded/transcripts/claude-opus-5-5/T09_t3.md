## Results by query

**q1: `component-code=…|8462-4&component-value-quantity=ge90`**
The two parameters are separate and not linked to the same component. A resource matches if it has a component coded 8462-4 and any component with a value ≥ 90.
- All bp-01 to bp-09 have a component coded 8462-4. This includes bp-06, whose diastolic component has a dataAbsentReason instead of a value.
- Each of those also has a systolic value ≥ 90, so every one satisfies the value criterion. Examples: bp-03 (120), bp-08 (128), bp-09 (139.6).
- hr-01 and sbp-01 have no components.

Result: bp-01 to bp-09.

**q2: composite `8462-4$ge90`**
The code and value must be in the same component. Diastolic values:

| Resource | Diastolic | Matches? |
|---|---|---|
| bp-01 | 80 | No |
| bp-02 | 95 | Yes |
| bp-03 | 80 | No |
| bp-04 | 92 | Yes |
| bp-05 | 88 | No |
| bp-06 | No value | No |
| bp-07 | 90 | Yes |
| bp-08 | 91 | Yes |
| bp-09 | 89.6 | No (ge compares exactly) |

Result: bp-02, bp-04, bp-07, bp-08.

**q3: systolic ≥ 140 OR diastolic ≥ 90, AND status=final**
- Systolic ≥ 140: bp-01 (150), bp-04 (145), bp-06 (160), bp-07 (140).
- Diastolic ≥ 90: bp-02, bp-04, bp-07, bp-08.
- bp-08 is removed because its status is entered-in-error.

Result: bp-01, bp-02, bp-04, bp-06, bp-07.

**q4: systolic ≥ 140 AND diastolic ≥ 90**
- Only bp-04 and bp-07 meet both conditions.
- bp-08 fails on systolic (128).
- bp-01 and bp-06 fail on diastolic.

Result: bp-04, bp-07.

**q5: composite `8480-6$140` (eq, implicit range [139.5, 140.5))**
- bp-07 (140) is in range.
- bp-09 (139.6) is also in range.

Result: bp-07, bp-09.

**q6: `code-value-quantity=8480-6$ge140`**
This searches `Observation.code` together with `Observation.valueQuantity`, not the components.
- The panels' top-level code is 85354-9, so none of them match.
- sbp-01 has code 8480-6 and value 152.

Result: sbp-01.

**q7: `value-quantity=gt90`**
This searches `Observation.valueQuantity` only. The query has no code or unit restriction, so heart rate counts too.
- hr-01 (98 /min) matches.
- sbp-01 (152) matches.
- The panels have no top-level value.

Result: hr-01, sbp-01.

**Registry takeaway:** q1 shows why the unlinked component parameters should not be used, since they flag every panel. The composite form (q3) is the correct way to express "systolic ≥ 140 or diastolic ≥ 90". Standalone systolic Observations like sbp-01 need a separate `code-value-quantity` query (q6).
