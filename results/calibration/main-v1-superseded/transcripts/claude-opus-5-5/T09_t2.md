# FHIR R4 Search Results for Task T09

## Key points

- **Separate parameters are evaluated independently.** In q1, `component-code` and `component-value-quantity` can each be satisfied by a different component. The values are not tied to the same component. The composite parameter `component-code-value-quantity` does tie the code and the value to the same component.
- **Quantity prefixes compare exactly.** `ge`, `gt` and `le` ignore the precision of the search number. Only `eq` (and no prefix) uses the implicit range, so `140` means [139.5, 140.5).
- **A `dataAbsentReason` component has no value.** bp-06's diastolic component has nothing to index, so no value-based condition can match it.
- **No unit or category filtering applies.** `value-quantity=gt90` matches any `Observation.valueQuantity` above 90, whatever the unit.

## Query results

**q1:** Every BP panel (bp-01 to bp-09) has a component coded 8462-4. bp-06 also qualifies, because the code is present even though the value is absent.
- Every panel also has some component value of 90 or more. In each case the systolic value alone (120 to 160) meets this.
- No status filter applies, so all nine panels match.

**q2:** The code and value must be in the same diastolic component.
- Matches: bp-02 (95), bp-04 (92), bp-07 (90), bp-08 (91).
- bp-09 does not match: 89.6 is below 90.
- bp-06 does not match: it has no value.

**q3:** The comma means OR, and `status=final` is also required.
- Systolic of 140 or more: bp-01, bp-04, bp-06, bp-07.
- Diastolic of 90 or more: bp-02, bp-04, bp-07, bp-08.
- bp-08 is removed because its status is `entered-in-error`.
- sbp-01 does not match because it has no components.

**q4:** Repeating the parameter means AND, so both conditions must hold. bp-04 (145/92) and bp-07 (140/90) match.

**q5:** No prefix means `eq`, which uses the implicit range [139.5, 140.5).
- bp-07 (140) and bp-09 (139.6) match.

**q6:** The code is matched against `Observation.code`, not the components.
- Only sbp-01 matches (8480-6, value 152).

**q7:** Matches hr-01 (98 /min) and sbp-01 (152 mmHg).
- The panels have no top-level `valueQuantity`, so they do not match.

**Registry implications:**
- q1 is a false-positive trap.
- q5 shows how implicit precision can pull in 139.6.
