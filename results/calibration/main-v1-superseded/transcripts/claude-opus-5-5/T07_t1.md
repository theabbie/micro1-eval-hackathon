# T07 Results: Body-Weight Quantity Searches

## How the server matches these queries

**Number matching (from the server rules)**
- `eq` (no prefix) and `ne` use the implicit precision range of the search number. Per R4, the lower bound is included and the upper bound is excluded:
  - `100` means [99.5, 100.5).
  - `100.0` means [99.95, 100.05).
- `gt`, `lt`, `ge` and `le` compare exactly against the stated number.

**Unit matching**
- `number|system|code`: the resource's `valueQuantity.system` and `valueQuantity.code` must both match. The display `unit` text does not matter.
  - **w-08** has no system, so it fails any query that names a system.
  - **w-09** has the display unit "kilograms", but its system and code (UCUM, `kg`) match.
- `number||code`: any system is accepted. The value is matched against either `code` or `unit`, so **w-08** (unit `kg`) matches.
- No unit conversion is done. **w-05** (220.5 `[lb_av]`) never matches a `kg` query.
- **w-10** has only `valueString`, so it is never indexed by `value-quantity`.

## Results per query

| Query | Rule applied | Matches |
|---|---|---|
| q1 `100\|UCUM\|kg` | [99.5, 100.5), UCUM kg | w-01 (100), w-02 (100.4), w-04 (99.5), w-06 (100.04), w-07 (99.94), w-09 (100.0) |
| q2 `100.0\|UCUM\|kg` | [99.95, 100.05), UCUM kg | w-01, w-06, w-09 |
| q3 `100\|\|kg` | [99.5, 100.5), code or unit = kg | q1 set plus w-08 |
| q4 `gt100\|UCUM\|kg` | value > 100 exactly | w-02, w-03, w-06 |
| q5 `ne100\|UCUM\|kg` | outside [99.5, 100.5), unit must still match | w-03 (100.5) |
| q6 `lt100.0\|\|kg` | value < 100 exactly, code or unit = kg | w-04, w-07 |

**Notes on specific resources**
- **w-03** (100.5) is excluded from q1 and q3 because the upper bound of the range is excluded.
- **w-09** (100.0) is excluded from q4 because 100.0 is not strictly greater than 100.
- **q5:** `ne` is a prefix, not the `:not` modifier. Resources with a different unit (w-05) or no quantity (w-10) are therefore not returned.
- **w-08** (100) is excluded from q6 because 100 is not strictly less than 100.0.

## Clinical observation

At the 100 kg dosing threshold, the w-05 pound import (220.5 lb ≈ 100.0 kg) is invisible to every `kg` query. If you can't rely on server-side unit conversion, normalize units at ingestion.
