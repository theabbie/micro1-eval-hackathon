# FHIR R4 Encounter Date Search Results for July 2024 (Task T06)

## Approach

**Time zone.** The server's local zone is America/New_York. In July and August 2024 this is EDT (−04:00). I converted every value to local time.

**Target ranges.**
- A missing `Period.end` means the encounter is ongoing, so the upper bound is +∞.
- A missing `Period.start` means the lower bound is −∞.
- A partial date such as `2024-07` covers its whole implicit range.

| id | Local range (EDT) | class |
|---|---|---|
| e-01 | 06-28 22:00 → 07-03 11:00 | IMP |
| e-02 | 07-30 20:00 → +∞ | IMP |
| e-03 | 07-15 09:00 → 09:30 | AMB |
| e-04 | 07-31 23:10 → 08-01 02:40 | EMER |
| e-05 | 07-31 22:00 → 22:30 (converted from Z) | AMB |
| e-06 | 07-01 00:00 → end of 07-31 | AMB |
| e-07 | 06-30 23:30 → 07-01 08:00 | OBSENC |
| e-08 | no period (no value) | IMP |
| e-09 | 06-30 23:30 → 23:50 (converted from Z) | AMB |
| e-10 | −∞ → end of 07-10 | AMB |

## Query results

**q1 `date=2024-07` (eq)**
- Rule: the target range must be fully inside the search range, July 1 00:00 to August 1 00:00 local.
- Matches: e-03, e-05, e-06.
- e-05 qualifies because 02:00Z is 22:00 EDT on July 31.
- e-02 is excluded because its range is unbounded above.
- e-10 is excluded because its range is unbounded below.

**q2 `ge2024-07-01` AND `le2024-07-31`**
- The `ge` condition (overlap allowed) reduces to: target end is after July 1 00:00. e-09 fails because it ends June 30 at 23:50. e-08 fails because it has no value.
- The `le` condition (overlap allowed) reduces to: target start is before August 1 00:00. All resources with a period pass.
- Matches: e-01, e-02, e-03, e-04, e-05, e-06, e-07, e-10.

**q3 class IMP AND `sa2024-06-30`**
- The IMP encounters are e-01, e-02 and e-08.
- Rule: the target must start at or after July 1 00:00 local.
- Matches: e-02 only.
- e-01 starts June 28, and e-08 has no value.

**q4 `gt2024-07-31`**
- Rule: the "range above" starts August 1 00:00, and the target must reach into it. `gt` does not get the overlap extension that `ge` has.
- Matches: e-02 (ongoing) and e-04 (ends August 1 at 02:40).
- e-05 is excluded because it ends July 31 at 22:30 local.
- e-06 is excluded because its range ends at the end of July 31.

**q5 `lt2024-07-01` AND class AMB or OBSENC**
- A code with no system matches that code in any system, so the class filter selects e-03, e-05, e-06, e-07, e-09 and e-10.
- Rule: the target must start before July 1 00:00 local.
- Matches: e-07, e-09 (both start June 30 at 23:30 local) and e-10 (lower bound −∞).
- e-06 is excluded because it starts exactly at July 1 00:00.

**q6 `date:missing=true`**
- Matches: only e-08, which has no period.
- e-10 is not missing because it has a period with an end.
