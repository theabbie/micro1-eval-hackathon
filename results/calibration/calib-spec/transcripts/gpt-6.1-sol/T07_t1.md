## Reply

For `eq` (the default) and `ne`, `100` uses the interval **[99.5, 100.5)**, while `100.0` uses **[99.95, 100.05)**. Quantity `gt` and `lt` use the stated numeric boundary without a precision adjustment.

A specified system and code must both match. With `||kg`, either the quantity’s code or its unit can match, so `w-08` qualifies. The pound quantity fails the unit constraint, and `w-10` has no searchable quantity.
