Only `occurrenceDateTime` values are date-typed and indexed. `occurrenceString` values (imm-03, imm-10) never match a date parameter.

**q1: `date=2019-05` (eq)**
The target range must lie entirely within May 2019. imm-01, imm-04, imm-05, imm-07 and imm-09 qualify. imm-02 (whole year) does not. imm-06 and imm-08 fall outside May. imm-03 and imm-10 have no indexed value.

**q2: `date=ne2019-05`**
ne matches indexed targets whose range is not fully contained in May 2019. That gives imm-02, imm-06 and imm-08. Resources with no value are not matched by ne; only :not includes them.

**q3: `date=2019` (eq)**
The target range must lie entirely within 2019 local time. imm-01, imm-02, imm-04, imm-05, imm-07, imm-08 (local 2019-12-31 23:30) and imm-09 qualify. imm-06 is 2018, so it is excluded.

**q4: `date=le2019-05-31&status=completed`**
le matches any indexed target whose range starts before the end of the search range, which is 2019-06-01T00:00 local. This rule covers both the range below and any overlap. The status filter removes imm-07 (not-done). imm-08 starts at 2019-12-31 23:30, so it is excluded. The matches are imm-01, imm-02, imm-04, imm-05, imm-06 and imm-09.

**q5: `date:missing=true`**
The date parameter has no indexed value for imm-03 and imm-10, because their occurrence is a string. These are the only resources returned.

**q6: `vaccine-code=http://hl7.org/fhir/sid/cvx|03&date=gt2019-05-14`**
The vaccine-code filter keeps imm-01, imm-02 and imm-03. gt2019-05-14 means the target must intersect the range from 2019-05-15T00:00 onward. imm-01 ends on 05-14, so it is excluded. imm-02 (whole year 2019) overlaps that range. imm-03 has no indexed date, so it is excluded.
