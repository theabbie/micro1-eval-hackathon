# T09: Component vs Composite Blood-Pressure Search Results

## q1: `component-code=…|8462-4&component-value-quantity=ge90`

The two parameters are evaluated independently. Neither one has to hold for the *same* component.

- **component-code = 8462-4:** bp-01 to bp-09 all have a diastolic component. This includes bp-06, whose diastolic component has a code but only a dataAbsentReason.
- **component-value-quantity ≥ 90:** *any* component counts, including the systolic one.
  - bp-01 (150): matches.
  - bp-02 (95): matches.
  - bp-03 (120/80): no match.
  - bp-04: matches.
  - bp-05 (systolic 135): matches.
  - bp-06 (systolic 160): matches.
  - bp-07: matches.
  - bp-08: matches.
  - bp-09 (139.6): matches.
- **Result:** bp-01, 02, 04, 05, 06, 07, 08, 09.

## q2: `component-code-value-quantity=…|8462-4$ge90`

The composite parameter requires the code and the value to be on the same component.

- Diastolic ≥ 90:
  - bp-02 (95): matches.
  - bp-04 (92): matches.
  - bp-07 (90): matches.
  - bp-08 (91): matches.
  - bp-09 (89.6): no match. The ge comparison is exact.
  - bp-06: no match, because its diastolic component has no value.

## q3: systolic ≥ 140 OR diastolic ≥ 90, plus `status=final`

- **Systolic ≥ 140:** bp-01, bp-04, bp-06, bp-07. bp-09 (139.6) does not match.
- **Diastolic ≥ 90:** bp-02, bp-04, bp-07, bp-08.
- **Union:** bp-01, 02, 04, 06, 07, 08.
- **Status filter:** bp-08 is removed because its status is entered-in-error.
- **Not included:** sbp-01 has no components, so the composite parameter cannot match it.
- **Result:** bp-01, 02, 04, 06, 07.

## q4: systolic ≥ 140 AND diastolic ≥ 90

The two composite parameters are combined with AND. Each one must be satisfied by its own component.

- **Result:** bp-04 and bp-07.

## q5: `…|8480-6$140` (eq)

- The search value 140 has an implicit range of [139.5, 140.5).
- **Matches:** bp-07 (140) and bp-09 (139.6).

## q6: `code-value-quantity=…|8480-6$ge140`

This parameter checks `Observation.code` and `Observation.valueQuantity`.

- **Match:** only sbp-01 (152).
- The panels have code 85354-9, so they do not match.

## q7: `value-quantity=gt90`

This checks the top-level `valueQuantity`, and no unit is specified in the query.

- **Matches:** hr-01 (98) and sbp-01 (152).
- The BP panels have no top-level value, so they do not match.

## Notes on the registry logic

- **q1 shows why separate parameters are risky.** bp-01, bp-05, bp-06, and bp-09 are false positives for "diastolic ≥ 90". Use the composite form instead.
- **Composite queries miss standalone Observations.** The q3/q4 queries do not find standalone systolic Observations like sbp-01. Add a `code-value-quantity` query to catch them.
- **Decimal readings fall through the exact cutoff.** bp-09 (139.6/89.6) is excluded under the exact ≥ comparison, even though q5 shows it would round to 140.
