## Reply

**Key semantics**

- **Separate parameters on the same element path (q1)** match independently. `component-code` and `component-value-quantity` can be satisfied by different components, so q1 does not require the diastolic code and the ≥90 value to sit on the same component.
- **Composite parameters (q2–q5)** require both halves to match the same component. Commas within one composite parameter are OR. Repeated composite parameters are ANDed across the resource.
- **Quantity comparisons:** `ge`, `gt` and similar prefixes compare exactly against stored values, so 89.6 is not ≥ 90. Bare `140` (eq) has the implicit range [139.5, 140.5), so 139.6 matches.
- **No status filter** unless `status=final` is given, so bp-08 (entered-in-error) is returned where it matches.
- **bp-06** has a diastolic component with only `dataAbsentReason`, so it has no diastolic value to match. Its systolic 160 still matches the systolic side of q1, q3 and q4 when those criteria are met.
- **sbp-01** is a standalone systolic Observation with a top-level code and `valueQuantity`, so it matches only the non-component queries (q6, q7).
- **hr-01** has no components and a top-level `valueQuantity` of 98, so it matches only q7.

**Per query**

- **q1:** All nine panels have a 8462-4 component, and every panel has a systolic value ≥ 90. Result: bp-01 through bp-09.
- **q2:** Diastolic ≥ 90 on the same component: bp-02 (95), bp-04 (92), bp-07 (90), bp-08 (91). bp-09 (89.6) fails.
- **q3:** (Systolic ≥ 140 OR diastolic ≥ 90) AND status=final. The OR set is bp-01, bp-02, bp-04, bp-06, bp-07, bp-08. bp-08 is removed by the status filter.
- **q4:** (Systolic ≥ 140) AND (diastolic ≥ 90), each parameter evaluated separately. Systolic ≥ 140: bp-01, bp-04, bp-06, bp-07. Diastolic ≥ 90: bp-02, bp-04, bp-07, bp-08. Intersection: bp-04, bp-07.
- **q5:** Systolic eq 140, implicit range [139.5, 140.5): bp-07 (140) and bp-09 (139.6).
- **q6:** Top-level code 8480-6 with `valueQuantity` ≥ 140. Only sbp-01 (152). Panels use code 85354-9 and have no top-level value.
- **q7:** Top-level `valueQuantity` > 90. hr-01 (98) and sbp-01 (152). Panels have no top-level value.
