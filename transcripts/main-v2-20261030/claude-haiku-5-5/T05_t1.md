## Key conversions (America/Los_Angeles)

- **c-07** `2020-01-01T07:30:00Z` = **2019-12-31 23:30 PST**, so its local date is 2019, not 2020.
- **c-08** `2020-01-01T09:00:00Z` = **2020-01-01 01:00 PST**.
- Date-only and partial values (`2018-03-02`, `2015`, `2019-10`–`2020-02`) are local.
- Only date-typed onsets are indexed: `onsetDateTime` and `onsetPeriod`. `onsetAge` (c-03) and `onsetString` (c-04) are not indexed for `onset-date`.
- Clinical-status token matching is case-sensitive and ignores the system. c-10's `Active` does not match `active`.

## q1: `clinical-status=active` & `onset-date=lt2020-01-01`

- Active resources: c-01, c-03, c-04, c-05, c-07, c-08 (c-10 excluded by case).
- c-01 (2018-03-02): before 2020 → **match**.
- c-03, c-04: no indexed onset → no.
- c-05 (period 2019-10 to 2020-02): the range below 2020-01-01 00:00 overlaps the period → **match**.
- c-07 (2019-12-31 23:30 local): before the start of 2020-01-01 → **match**.
- c-08 (2020-01-01 01:00 local): not before 2020-01-01 00:00 → no.

Result: c-01, c-05, c-07.

## q2: `clinical-status=active,recurrence,relapse` & `onset-date=ge2020-01-01`

- Matching status: c-01, c-02, c-03, c-04, c-05, c-07, c-08.
- ge matches targets that overlap the search day or lie after its end. Equivalently, the target's range ends on or after 2020-01-01 00:00 local.
- c-01 (2018), c-02 (2019-07-01): no.
- c-03, c-04: no indexed onset → no.
- c-05: period end 2020-02-29 overlaps the search day → **match**.
- c-07 (2019-12-31 23:30 local): ends before 2020-01-01 → no.
- c-08 (2020-01-01 01:00 local): falls within the search day → **match**.

Result: c-05, c-08.

## q3: `onset-date:missing=true`

Resources with no indexed date-typed onset value:
- c-03 (onsetAge), c-04 (onsetString), c-11 (no onset).

All other resources have a dateTime or Period onset. c-09 and c-10 have values, so they are not missing.

Result: c-03, c-04, c-11.

## q4: `clinical-status:not=active`

`:not` returns resources without a matching value, including those with no value at all.
- Excluded (have `active`): c-01, c-03, c-04, c-05, c-07, c-08.
- Included:
  - c-02 (`recurrence`)
  - c-06 (`resolved`)
  - c-09 (no clinicalStatus, so no value)
  - c-10 (`Active` ≠ `active`, case-sensitive)
  - c-11 (`inactive`)

Result: c-02, c-06, c-09, c-10, c-11.

Note: c-09 is `entered-in-error` in `verificationStatus`, but this query does not filter on verification, so it is included.

## q5: `onset-date=2019`

The search range is 2019-01-01 00:00 to 2019-12-31 23:59:59.999 local. `eq` requires the target range to be fully contained in it.
- c-01 (2018), c-06 (2015), c-08 (2020-01-01 01:00 local), c-09 (2017), c-10 (2016): no.
- c-02 (2019-07-01): fully contained → **match**.
- c-05 (2019-10 to 2020-02): extends past the range → no.
- c-07 (2019-12-31 23:30 local): contained → **match**.

Result: c-02, c-07.
