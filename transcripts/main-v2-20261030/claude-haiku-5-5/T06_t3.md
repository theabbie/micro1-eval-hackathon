## Conventions used

- **Local July 2024 (EDT, UTC-4):** `[2024-07-01T00:00-04:00, 2024-08-01T00:00-04:00)`, which is `[2024-07-01T04:00Z, 2024-08-01T04:00Z)` in UTC.
- **Period matching:** a Period is treated as a range from start to end. A missing end is open-ended (+∞), and a missing start is unbounded below (−∞).
- **Prefixes (R4 table, with this server's choices):**
  - `eq`: the target range is fully contained in the search range.
  - `gt`: the target intersects the range above the search range's end.
  - `lt`: the target intersects the range below the search range's start.
  - `ge` / `le`: overlap, or the same as `gt` / `lt` respectively.
  - `sa`: the target lies entirely after the search range's end.
- **Multiple `date` params** on one query are ANDed. Comma-separated `class` values are ORed.

## Query results

- **q1 `date=2024-07` (eq):** Only targets fully inside July qualify. e-03, e-05, and e-06 do. e-01, e-02, e-04, e-07, and e-10 extend beyond July. e-08 has no date. e-09 is in June.
- **q2 `ge2024-07-01` AND `le2024-07-31` (overlap):** Targets that overlap July qualify. That is e-01, e-02, e-03, e-04, e-05, e-06, e-07, and e-10. e-08 has no date. e-09 ends before July 1.
- **q3 `class=…|IMP` AND `sa2024-06-30`:** `sa` requires the target to start after June 30 ends. Among IMP encounters, only e-02 qualifies. e-01 starts on June 28, and e-08 has no date.
- **q4 `gt2024-07-31`:** The target must reach past the end of July 31 (08-01 00:00 local). e-02 (open-ended) and e-04 (ends 08-01 02:40 local) qualify. e-05 ends on July 31 locally, so it does not.
- **q5 `lt2024-07-01` AND `class=AMB,OBSENC` (OR):** The target must start before July 1 local. e-07 (OBSENC, starts 06-30 23:30), e-09 (AMB, starts 06-30 23:30 local), and e-10 (AMB, unbounded start) qualify. e-06 starts exactly at July 1 00:00, so it does not.
- **q6 `date:missing=true`:** Only e-08 lacks a date value. e-10 has an end date, so it has a value.
