## Reasoning

**Matching rules applied**
- Search values have an implicit range from their written digits, used by `eq` and `ne`. `100` means [99.5, 100.5), and `100.0` means [99.95, 100.05).
- Stored values are exact points. `gt`, `lt`, and so on compare exactly against the search number.
- Quantity search matches on `system` and `code` (not `unit`). A resource with no `system`/`code` does not match a query that specifies them. A query with an empty system (`||kg`) matches on code only.
- No unit conversion, so `lb` values never match `kg` queries.
- `ne` is the negation of `eq` over the implicit range. Resources with no quantity value (w-10) are not matched by `ne`. The `:not` note doesn't apply to `ne`.

**Resource notes**
- w-05 (220.5 lb, code `[lb_av]`): excluded from every query because the code is not `kg`.
- w-08 (100 kg, `unit` only, no `system` or `code`): excluded from every query because it has no code to match.
- w-09 (100.0, code `kg`, unit "kilograms"): matched on code, so it is included wherever the value is in range. The unit text is ignored.
- w-10 (`valueString`, "patient refused"): has no quantity, so it never matches.

**q1** `100|http://unitsofmeasure.org|kg`: range [99.5, 100.5).
- Included: w-01 (100), w-02 (100.4), w-04 (99.5, lower bound inclusive), w-06 (100.04), w-07 (99.94), w-09 (100.0).
- Excluded: w-03 (100.5, upper bound exclusive), w-05 (lb), w-08 (no system), w-10 (no value).

**q2** `100.0|http://unitsofmeasure.org|kg`: range [99.95, 100.05).
- Included: w-01, w-06 (100.04), w-09.
- Excluded: w-02 (100.4), w-04 (99.5), w-07 (99.94), w-03 (100.5), w-08 (no system).

**q3** `100||kg`: range [99.5, 100.5), code `kg` only.
- Same as q1, since w-08 has no code and w-05 has a different code.
- Included: w-01, w-02, w-04, w-06, w-07, w-09.

**q4** `gt100|http://unitsofmeasure.org|kg`: exact comparison, value > 100.
- Included: w-02 (100.4), w-03 (100.5), w-06 (100.04).
- Excluded: w-01 and w-09 (exactly 100), w-04, w-07, w-05 (lb), w-08 (no system).

**q5** `ne100|http://unitsofmeasure.org|kg`: outside [99.5, 100.5).
- Included: w-03 (100.5 is outside the half-open range).
- Excluded: every other in-range kg value, w-05 (lb), w-08 (no system), w-10 (no value).

**q6** `lt100.0||kg`: exact comparison, value < 100, code `kg` only.
- Included: w-04 (99.5), w-07 (99.94).
- Excluded: w-01 and w-09 (exactly 100), w-02, w-03, w-06 (values ≥ 100), w-08 (no code), w-05 (code `[lb_av]`).
