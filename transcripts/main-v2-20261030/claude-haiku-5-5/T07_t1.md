## Matching rules applied

- **Search value ranges:** `100` has the implicit range [99.5, 100.5). `100.0` has [99.95, 100.05). These apply to `eq` and `ne` only.
- **Stored values:** exact points, with their written precision ignored.
- **`gt`/`lt`:** compare exactly against the written number, so `lt100.0` means `< 100.0`.
- **`ne`:** matches values outside the implicit range.
- **System and code:** a `system|code` query needs both to match. A `||code` query matches the code on any system. The `code` element must be present.
- **Excluded resources:**
  - `w-08` has a unit but no `code` element, so it never matches a code-based quantity search.
  - `w-05` is in pounds (`[lb_av]`), so it never matches `kg`. No unit conversion is done.
  - `w-10` has only a `valueString`, which is not indexed for quantity search.
