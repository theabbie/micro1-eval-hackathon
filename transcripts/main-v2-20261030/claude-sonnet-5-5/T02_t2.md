**Reference range.** The local day 2024-11-03 in America/New_York runs from 2024-11-03T04:00Z (00:00 EDT) to 2024-11-04T05:00Z (00:00 EST), exclusive. It is 25 hours long.

**Resources as UTC instants or ranges**

| id | UTC value |
|---|---|
| k-01 | 11-03 04:30Z |
| k-02 | 11-03 03:30Z |
| k-03 | 11-04 04:30Z |
| k-04 | 11-04 05:00Z |
| k-05 | 11-03 05:30Z |
| k-06 | 11-03 06:30Z |
| k-07 | 11-03 06:30Z |
| k-08 | date 11-03, which is the same range as the local day [04:00Z, 11-04 05:00Z) |
| k-09 | 23:45 local (EST) = 11-04 04:45Z |
| k-10 | month 2024-11, from 11-01 04:00Z to 12-01 05:00Z |
| k-11 | period 11-03 02:00Z to 11:00Z |
| k-12 | 11-03 05:00Z |
| k-13 | 11-03 06:00Z |

**q1 (eq).** The target range must be fully contained in the search day.
- Contained: k-01, k-03, k-05, k-06, k-07, k-08, k-09, k-12, k-13.
- Excluded: k-02 (before the day), k-04 (exactly at the exclusive end), k-10 (month is wider than the day), k-11 (period starts before the day).

**q2 (ge 01:00-04:00 and lt 01:00-05:00).** The two parameters are ANDed.
- ge 05:00Z: the target must overlap [05:00Z, 05:01Z) or lie above it.
- lt 06:00Z: the target must intersect the range below 06:00Z, so its start must be before 06:00Z.
- k-05 qualifies (05:30Z).
- k-08 qualifies: its end is above the ge range and its start is before 06:00Z.
- k-10 qualifies by the same reasoning.
- k-11 qualifies: its end of 11:00Z satisfies ge and its start of 02:00Z satisfies lt.
- k-12 qualifies: 05:00:00Z overlaps the ge range and is before 06:00Z.
- k-13 fails lt because it is not below 06:00Z.
- k-01 and k-02 fail ge.
- k-03, k-04, k-06, k-07 and k-09 fail lt.

**q3 (sa).** The target must start at or after the end of the search range (11-04 05:00Z). Only k-04 qualifies.

**q4 (eb).** The target must end at or before the start of the search range (11-03 04:00Z). Only k-02 qualifies.

**q5 (ne).** This is the complement of q1: k-02, k-04, k-10, k-11.

**q6 (eq 2024-11-03T01:30-05:00).** This is 06:30Z with minute precision, so the range is [06:30, 06:31)Z. k-06 and k-07 both fall inside it.
