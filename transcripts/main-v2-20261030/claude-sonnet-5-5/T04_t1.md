**Time-zone conversions (America/Chicago)**
- May and June are CDT (UTC-5). January and December are CST (UTC-6).
- imm-05 is 2019-06-01T03:30Z, which is 2019-05-31 22:30 CDT.
- imm-06 is 2019-01-01T05:00Z, which is 2018-12-31 23:00 CST.
- imm-08 is 2020-01-01T05:30Z, which is 2019-12-31 23:30 CST.
- imm-09 has no offset, so it is 2019-05-31 23:59 CDT, which is 2019-06-01T04:59Z.
- imm-03 and imm-10 use `occurrenceString`. Strings are not date-typed, so they are not indexed by `date`.

**q1: `date=2019-05`**
- The search range is [2019-05-01 CDT, 2019-06-01 CDT). `eq` requires the target's range to be fully contained in it.
- imm-01, imm-04, imm-05, imm-07 and imm-09 are contained.
- imm-02 (the whole year) is not contained. imm-06 and imm-08 fall outside the range.

**q2: `date=ne2019-05`**
- `ne` matches indexed targets whose range is not fully contained in the search range. These are imm-02, imm-06 and imm-08.
- imm-03 and imm-10 have no indexed value, and the `ne` prefix does not return those (only `:not` does).

**q3: `date=2019`**
- The search range is [2019-01-01 00:00 CST, 2020-01-01 00:00 CST), which is 06:00Z to 06:00Z.
- imm-01, imm-02, imm-04, imm-05, imm-07, imm-08 (2019-12-31 23:30 CST) and imm-09 are contained.
- imm-06 is 2018-12-31 23:00 CST, which is before the range, so it does not match.

**q4: `date=le2019-05-31&status=completed`**
- The search range is [05-31 CDT, 06-01 CDT), ending at 2019-06-01T05:00Z. `le` matches any target that starts before that end, because it is either below the range or overlaps it.
- Among completed resources, imm-01, imm-02, imm-04, imm-05, imm-06 and imm-09 (04:59Z) match.
- imm-08 starts in 2020, so it does not match. imm-07 is excluded because its status is `not-done`.

**q5: `date:missing=true`**
- imm-03 and imm-10 have no indexed date value.

**q6: `vaccine-code=cvx|03&date=gt2019-05-14`**
- The CVX code 03 matches imm-01, imm-02 and imm-03.
- `gt` requires the target to overlap the range above 2019-05-15 00:00 CDT.
- imm-01 ends exactly at that boundary, and its end is exclusive, so it does not match.
- imm-02 (the whole year 2019) overlaps the range above, so it matches.
- imm-03 has no indexed date, so it does not match.
