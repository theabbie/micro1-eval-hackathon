## Reply

**Indexing.** `onset-date` indexes only `onsetDateTime` and `onsetPeriod`. c-03 (Age), c-04 (string) and c-11 (no onset) have no indexed value.

**Local time.** America/Los_Angeles is UTC-8 in January, so 2020-01-01 local begins at 2020-01-01T08:00Z. That gives:
- c-07 (`2020-01-01T07:30Z`) is 2019-12-31 23:30 PST, so it falls before 2020.
- c-08 (`2020-01-01T09:00Z`) is 2020-01-01 01:00 PST, so it falls in 2020.

**Token matching.** `clinical-status=active` has no system, so it matches code `active` in any system. Matching is case-sensitive, so c-10's local code `Active` does not match. c-09 has no clinicalStatus.

**q1: `clinical-status=active` and `onset-date=lt2020-01-01`**
- Active resources with an indexed onset are c-01, c-05, c-07 and c-08.
- The range below the search value ends at 2020-01-01 local, and a target matches if it intersects that range.
- c-01 matches (2018).
- c-05 matches because its period starts 2019-10, which overlaps the range below.
- c-07 matches because it is 23:30 PST on 12-31.
- c-08 is excluded because it is after the start of 2020.

**q2: `clinical-status=active,recurrence,relapse` and `onset-date=ge2020-01-01`**
- c-01 and c-02 (2019-07-01) are before 2020 and do not match.
- c-05's period runs to the end of 2020-02, so it overlaps and matches.
- c-07 is 2019-12-31 local and does not match.
- c-08 is inside the search day and matches.
- c-10 does not match because of its case-sensitive `Active` code.

**q3: `onset-date:missing=true`**
- c-03, c-04 and c-11 have no indexed onset value.

**q4: `clinical-status:not=active`**
- `:not` also returns resources with no value for the parameter.
- c-02 (recurrence), c-06 (resolved) and c-11 (inactive) match.
- c-09 (no clinicalStatus) and c-10 (`Active`, a different code) also match.

**q5: `onset-date=2019`**
- The search range is 2019-01-01 through 2019-12-31 in local time, and the target range must be fully contained in it.
- c-02 matches.
- c-07 matches because 2019-12-31 23:30:00 PST is a point inside 2019 local.
- c-05 extends into 2020 and is not contained.
- c-01 and c-06 are other years.
