**q1: `date=2019-05`**
The implicit range is May 2019. Default `eq` requires the resource's range to be contained in the search range.
- Matches: 01, 04, 05, 07, 09.
- imm-02 is a whole-year range, so it is not contained.
- imm-06 and imm-08 are outside May.

**q2: `date=ne2019-05`**
`ne` returns indexed resources whose range is not fully contained in the search range. Resources with no indexed value (imm-03, imm-10) do not match, because only `:not` returns those.
- Matches: 02, 06, 08.

**q3: `date=2019`**
The implicit range is all of 2019 local time.
- Matches: 01, 02, 04, 05, 07, 08, 09.
- imm-06 falls on 2018-12-31 local, so it is excluded.

**q4: `date=le2019-05-31&status=completed`**
The search range is 2019-05-31 for the whole day. `le` matches any resource that starts before the end of that range, which means before 2019-06-01 00:00 local. This includes overlaps.
- Date matches: 01, 02, 04, 05, 06, 07, 09.
- imm-08 starts in December 2019, so it is excluded.
- `status=completed` removes imm-07, which is not-done.
- Result: 01, 02, 04, 05, 06, 09.

**q5: `date:missing=true`**
Resources with no indexed date value are imm-03 and imm-10, because string occurrences are not indexed.

**q6: `vaccine-code=cvx|03&date=gt2019-05-14`**
- The vaccine-code filter keeps 01, 02, 03.
- The range above the search value starts at 2019-05-15 00:00 local, and `gt` requires the resource to intersect that range.
- imm-01 ends exactly at that boundary, so it does not match.
- imm-02 spans the whole of 2019, so it intersects and matches.
- imm-03 has no indexed date, so it does not match.
- Result: 02.
