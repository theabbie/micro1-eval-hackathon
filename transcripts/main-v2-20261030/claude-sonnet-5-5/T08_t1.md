**Matching rules used:**
- **eq:** the target range must be fully contained in the search range. An open-ended period is never contained.
- **ne:** the target is not fully contained in the search range.
- **ge/le:** ge matches any target whose end is at or after the search start. le matches any target whose start is at or before the search end. Open-ended periods match ge.
- **eb:** the target must end at or before the search start and must not overlap the search range.
- **sa:** the target must start at or after the search end and must not overlap the search range.
- **gt:** the target must overlap the range above the search value, which starts at the end of the search range.
