## Reply

**Indexing.** `onset-date` indexes only `onsetDateTime` and `onsetPeriod`. `onsetAge` (c-03) and `onsetString` (c-04) are not indexed, and c-11 has no onset at all.

Normalised onset values, in America/Los_Angeles:

| Resource | Onset (LA time) | Clinical status |
|---|---|---|
| c-01 | 2018-03-02 (whole day) | active |
| c-02 | 2019-07-01 (whole day) | recurrence |
| c-05 | period 2019-10-01 → 2020-02-29 end | active |
| c-06 | 2015 (whole year) | resolved |
| c-07 | 2019-12-31T23:30 | active |
| c-08 | 2020-01-01T01:00 | active |
| c-09 | 2017-05-05 | none (only `verificationStatus`) |
| c-10 | 2016-08-19 | local system, code `Active` |

The two instants are the traps. c-07 is 2020-01-01T07:30Z, which is still 2019 in LA. c-08 is 2020-01-01T09:00Z, which is already 2020 in LA.

**q1** (`clinical-status=active`, `onset-date=lt2020-01-01`)
- The range below ends at 2020-01-01T00:00 LA, and `lt` has no overlap rule.
- c-01 and c-07 are active and fall entirely before that point.
- c-05 straddles the boundary, so it is excluded.
- c-08 is after the boundary.
- c-10's code `Active` does not match `active`, because matching is case-sensitive.
- c-03 and c-04 are not indexed.

**q2** (`clinical-status=active,recurrence,relapse`, `onset-date=ge2020-01-01`)
- `ge` matches values in the range above, or any value that overlaps the search day 2020-01-01.
- c-08 falls inside 2020-01-01 LA, so it matches.
- c-05 overlaps the search range and is active, so it matches.
- c-07 is 2019-12-31 LA, so it does not match.
- c-02 (recurrence) and c-01 are earlier than the range.

**q3** (`onset-date:missing=true`)
- c-03 (Age), c-04 (string) and c-11 (no onset) have no indexed value.

**q4** (`clinical-status:not=active`)
- `:not` also returns resources with no value for the parameter.
- c-02 (recurrence), c-06 (resolved) and c-11 (inactive) match.
- c-09 has no `clinicalStatus`, so it matches.
- c-10 has `Active`, which is not equal to `active`, so it matches.

**q5** (`onset-date=2019`)
- The search range is 2019-01-01T00:00 to 2020-01-01T00:00 LA.
- The target must lie within that range.
- c-02 and c-07 (2019-12-31T23:30 LA) match.
- c-05 extends into 2020, so it does not match.
