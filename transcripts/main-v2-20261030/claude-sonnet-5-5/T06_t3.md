## Reasoning

July 2024 is EDT (UTC-4). Normalized to local time:

| id | effective range (local) |
|---|---|
| e-01 | 06-28 22:00 → 07-03 11:00 |
| e-02 | 07-30 20:00 → open-ended |
| e-03 | 07-15 09:00 → 09:30 |
| e-04 | 07-31 23:10 → 08-01 02:40 |
| e-05 | 07-31 22:00 → 22:30 (08-01T02:00Z is still July 31 locally) |
| e-06 | 07-01 00:00 → 07-31 23:59:59.999 (month precision) |
| e-07 | 06-30 23:30 → 07-01 08:00 |
| e-08 | no period (not indexed) |
| e-09 | 06-30 23:30 → 23:50 (03:30Z is June 30 locally) |
| e-10 | open start → 07-10 (whole day) |

**q1: `date=2024-07` (eq).** The target range must be fully contained in July. Open-ended periods (e-02, e-10) are not contained. e-04 runs past the end of July, and e-01 and e-07 start before it. This leaves e-03, e-05 and e-06.

**q2: `ge2024-07-01` AND `le2024-07-31`.** Both parameters must match.
- `ge` matches when the target overlaps `[07-01, ∞)`. Everything except e-08 and e-09 (which ends June 30) matches.
- `le` matches when the target overlaps `(-∞, 08-01)`, which every indexed resource does. e-10 has no start, so it is unbounded below.
- The intersection is e-01, e-02, e-03, e-04, e-05, e-06, e-07 and e-10.

**q3: `class=…|IMP` and `date=sa2024-06-30`.** `sa` needs the target to lie entirely in the range above, so it must start at or after 07-01 00:00. Of the IMP encounters, e-01 starts too early, e-02 qualifies, and e-08 has no period. This leaves e-02.

**q4: `gt2024-07-31`.** The range above starts at 08-01 00:00, so the target must end after that or be open-ended. e-02 is open-ended and e-04 ends 08-01 02:40. e-05 ends July 31 22:30, so it does not match.

**q5: `lt2024-07-01` and `class=AMB,OBSENC`.** `lt` needs the target to start before 07-01 00:00 or have no start. The class codes are OR'd, with no system given.
- e-07 matches (OBSENC, starts 06-30 23:30).
- e-09 matches (AMB, starts 06-30 23:30).
- e-10 matches (AMB, no start).
- e-06 starts exactly at 07-01 00:00, so it does not match.
- e-03 and e-05 start later.

**q6: `date:missing=true`.** Only e-08 has no period. e-10 has an end, so it is indexed.
