## Results by query

**q1: `_has` with separate code and value-quantity conditions.** Each `_has` is evaluated independently, so the HbA1c observation and the `gt9` observation can be different ones. Patients with an HbA1c observation are pt-1, pt-2, pt-3, and pt-5. pt-4 has no HbA1c. The value condition is met by pt-1 (o-1), pt-2 (o-4, 250 mg/dL, a different code), pt-3 (o-5), and pt-5 (o-6 or o-7). pt-2 matches only through o-4, which is a different observation from its HbA1c o-3. Nothing filters on status, so the entered-in-error o-6 still counts. Result: pt-1, pt-2, pt-3, pt-5.

**q2: `_has` with a composite.** The code and value must match the same Observation. pt-1 (o-1, 9.5) and pt-3 (o-5, 9.2) match. pt-5 matches via o-6 (10.1), which is entered-in-error but is not filtered out. pt-2 fails because o-3 is 7.0. Result: pt-1, pt-3, pt-5.

**q3: q2 plus a separate `status=final` `_has`.** pt-1 has final o-1. pt-3 has final o-5. pt-5 has final o-7, which is independent of o-6, so pt-5 still matches. Result: pt-1, pt-3, pt-5.

**q4: Observation composite plus a chained gender filter.** The composite matches o-1 (9.5), o-5 (9.2), o-6 (10.1), and o-8 (11.0). The chain `patient.gender=female` keeps o-1 (pt-1 is female) and o-5 (pt-3 is female). o-6 is pt-5 (male). o-8 references pt-9, which is not on this server, so the chain fails. Result: o-1, o-5.

**q5: Observation composite with `_include=Observation:patient`.** The matches are o-1, o-5, o-6, and o-8. The include only fetches referenced patients that exist on this server. o-8 references pt-9, which is absent, so no patient is included for it. The include set is Patient/pt-1, pt-3, and pt-5. Included resources are not filtered by the search criteria.

**q6: `patient=pt-2` with `_revinclude=Provenance:target`.** The matches are o-3 and o-4. prov-2 targets both, so it is included. prov-1 targets o-1 and is not included. Result: match o-3, o-4; include prov-2.

**q7: Patient search with two `_revinclude`s.** The matches are female patients with an HbA1c observation. pt-1 and pt-3 qualify. pt-4 is female but has no HbA1c. The `_revinclude=Provenance:target` pulls prov-3, which targets Patient/pt-1. prov-1 targets an Observation, not a matched patient, so it is excluded. The `_revinclude=Observation:patient` pulls every observation whose subject is pt-1 or pt-3, which is o-1, o-2, and o-5. Result: match pt-1, pt-3; include o-1, o-2, o-5, prov-3.
