## Reply

**q1: `component-code` and `component-value-quantity` as separate parameters.** These are plain parameters, not a composite, so each can be satisfied by a different component. Any panel with a 8462-4 component matches, and every panel's systolic value is at least 90. This includes bp-06, whose diastolic component has a `dataAbsentReason` but still has a code. bp-08 (entered-in-error) is included because no status filter is applied. The standalone `sbp-01` and `hr-01` have no components.
Matches: bp-01 through bp-09.

**q2: composite `component-code-value-quantity` for diastolic ≥ 90.** The code and value must come from the same component. Diastolic values at or above 90 are bp-02 (95), bp-04 (92), bp-07 (90, exact), and bp-08 (91). bp-06 has no value, so it does not match.

**q3: comma-separated composite values with `status=final`.** The comma makes the two composite pairs an OR. The pairs are systolic ≥ 140 (bp-01, bp-04, bp-06, bp-07; bp-09 at 139.6 is excluded) and diastolic ≥ 90 (bp-02, bp-04, bp-07, bp-08). The union is bp-01, bp-02, bp-04, bp-06, bp-07, bp-08. `status=final` removes bp-08.

**q4: repeated composite parameter.** Repeating the parameter is an AND, with each occurrence evaluated independently. Systolic ≥ 140 gives bp-01, bp-04, bp-06, bp-07. Diastolic ≥ 90 gives bp-02, bp-04, bp-07, bp-08. The intersection is bp-04 and bp-07.

**q5: composite with no prefix (eq).** "140" has the implicit range [139.5, 140.5). Stored values are exact points, so 140 matches and 139.6 also falls inside the range. Systolic components matching are bp-07 (140) and bp-09 (139.6).

**q6: `code-value-quantity` (composite on the resource itself).** This uses top-level `Observation.code` and `Observation.valueQuantity`, not components. Only `sbp-01` has code 8480-6 at the top level, and its value 152 is ≥ 140. The panels have code 85354-9 and no top-level value.

**q7: `value-quantity=gt90` on top-level `valueQuantity`.** Only `hr-01` (98) and `sbp-01` (152) have a top-level value. Panels have none, so they never match.
