# FHIR R4 Search Results for T09: Component vs Composite Blood-Pressure Search

## Key rules applied

- **Separate parameters do not share a component.** `component-code` and `component-value-quantity` given as separate parameters can each match a different component of the same Observation. A composite parameter (`$`) requires both parts to match within the same component.
- **Comma means OR, repeated parameters mean AND.** In a composite, a comma separates alternatives. Repeating the parameter means each instance must match, possibly via different components.
- **Prefixes compare exactly.** `ge`, `gt`, `le` and `lt` ignore the search value's precision. With no prefix, `eq` uses the implicit range of the written value: `140` means [139.5, 140.5).
- **Units are not checked.** A quantity search with no unit matches any unit.
- **`dataAbsentReason` gives no value.** bp-06's diastolic component has a code but no `valueQuantity`, so it is indexed for `component-code` but not for `component-value-quantity`.
- **Value and component paths are separate.** `value-quantity` and `code-value-quantity` use `Observation.code` and `Observation.valueQuantity`. They never look at components, and component parameters never look at top-level values.

## Per-query analysis

**q1** – Every panel (bp-01 to bp-09) has a component coded 8462-4, including bp-06. The second parameter only needs any component value ≥ 90.
- Systolic values ≥ 90: bp-01, bp-05, bp-06, bp-09.
- Diastolic or systolic ≥ 90: bp-02, bp-04, bp-07, bp-08.
- Only bp-03 (120/80) fails.
- Status is not filtered.
- **Result:** bp-01, 02, 04, 05, 06, 07, 08, 09.

**q2** – The diastolic component itself must be ≥ 90.
- Matches: bp-02 (95), bp-04 (92), bp-07 (90), bp-08 (91).
- bp-09 (89.6) is below 90 under exact comparison.
- bp-06 has no diastolic value.

**q3** – Systolic ≥ 140 OR diastolic ≥ 90, AND status = final.
- Systolic ≥ 140: bp-01, 04, 06, 07. bp-09 (139.6) does not qualify, and sbp-01 has no components.
- Diastolic ≥ 90: bp-02, 04, 07, 08.
- `status=final` removes bp-08.
- **Result:** bp-01, 02, 04, 06, 07.

**q4** – Systolic ≥ 140 AND diastolic ≥ 90: bp-04 and bp-07.

**q5** – Systolic eq 140, with range [139.5, 140.5): bp-07 (140) and bp-09 (139.6).

**q6** – Top-level code 8480-6 with value ≥ 140: sbp-01 (152).

**q7** – Top-level `valueQuantity` > 90, any unit: hr-01 (98 /min) and sbp-01 (152).

- q5 shows that `eq` with an implicit range also matches 139.6.
